# RL

To run this code you must use python 3.13

GPU hasn't been tested, though it works on CPU, will probably test later

Running instructions:
```
git clone https://github.com/engibengi/RL
cd ./RL
git clone https://github.com/giorgiofranceschelli/Gymnasium-Stag-Hunt
python3.13 -m venv .venv
source ./.venv/bin/activate
pip install -r requirements.txt
pip install ./Gymnasium-Stag-Hunt
python ./staghunt.py
```
